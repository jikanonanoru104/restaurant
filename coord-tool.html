참여 업체 좌표 보정 도구 (내부용)

① 지오코딩 일괄 배치로 주소 기준 좌표를 깔고 → ② 지도를 확대해 실제 가게 아이콘 위를 클릭하면 그 자리로 좌표가 잡히고 다음 업체로 자동 이동함 → ③ 하단 배열을 복사해 index.html의 STORES에 붙여넣으면 됨.
핀을 직접 끌어서 미세 조정하는 것도 됨. ※ API 키가 도메인에 묶여 있어 배포된 사이트 주소로 접속해야 동작함.
